# Security Policy

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Use GitHub's [private vulnerability reporting][gh-pvr] for this repo, or
email the maintainer (see commit history). You should expect an
acknowledgement within 72 hours.

## Supported versions

Only the latest minor release receives security fixes during the v1.x line.

[gh-pvr]: https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability
