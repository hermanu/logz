# Contributor Covenant Code of Conduct

This project adopts the [Contributor Covenant v2.1][cc].

In short: be kind, assume good faith, and give space for disagreement
without making it personal. Harassment, discrimination, or hostility are
not tolerated.

## Reporting

Report unacceptable behavior to the maintainers via the contact in
[SECURITY.md](SECURITY.md). Reports will be handled confidentially.

[cc]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
